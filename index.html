We respect the confidentiality of our developers and the telemetry profiles of players within protected experiences. This Privacy Policy details the exact perimeter of data ingestion performed by VEX Anti-Cheat in full conformance with international privacy regulations and platform mandates.

1. Data Minimization Principles (What We Ingest)

In accordance with Discord’s Data Minimization policies, VEX restricts all backend tracking to strictly necessary network security telemetry:

  • Developer & Administration Records: We register your discord_id and discord_tag to uniquely index database authorization parameters for your web dashboard session.
  • Roblox Telemetry Metrics: When a memory breach or tool exploit occurs, our runtime script pushes the target player's Roblox Username, roblox_uid, current place_id, and the localized nature of the hack (e.g. Speed Hack, Flight, Exploit Executor flag) to our system database.

2. Data Isolation & Security Protocols

We take security very seriously. All requests handled through our interface use secure proxy routing:

  • No PII Storage: We do not capture, record, or request Personally Identifiable Information (PII) such as IP addresses, real-world locations, emails, or payment logs.
  • Encryption Standards: Data flowing through our API pathways utilizes cryptographic handshakes to prevent packet-sniffing or database tampering.
